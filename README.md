# The Ideation Lab

The official digital identity for **The Ideation Lab — NEC 2026 × E-Cell IIT Bombay**.

## Run locally

This is a dependency-light static site. Open `index.html` directly, or serve the folder with any static server:

```bash
npx serve .
```

## Updating content

Verified team members, milestones, gallery items and events live in `data.js`. Replace the clearly marked placeholders there as information becomes available; the UI does not need to change.
